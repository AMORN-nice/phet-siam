# เพชรสยาม

เกมสะสมอัญมณี ธีมสยามโบราณ เล่นออนไลน์แบบเรียลไทม์กับเพื่อน 2–5 คน ภาพทั้งหมดเป็น pixel art ที่ทำด้วย PixelLab

## ลองเล่นในเครื่องตัวเอง

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป

```bash
npm install
npm start
```

แล้วเปิด http://localhost:3000 ถ้าอยากลองเล่นหลายคน ให้เปิดหลายแท็บ (แต่ละแท็บต้องใช้คนละเบราว์เซอร์ หรือเปิดโหมดไม่ระบุตัวตน เพราะที่นั่งของแต่ละคนผูกกับเบราว์เซอร์)

## เอาขึ้นเว็บให้เพื่อนเล่น (ฟรี ด้วย Render)

ใช้เวลาประมาณ 10 นาที ทำครั้งเดียวจบ

### 1. เอาโค้ดขึ้น GitHub
1. สมัครหรือล็อกอิน https://github.com
2. กด **New repository** ตั้งชื่อเช่น `phet-siam` เลือก **Public** หรือ **Private** ก็ได้ แล้วกด **Create repository**
3. ในหน้า repo ที่เพิ่งสร้าง กด **uploading an existing file** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดจากไฟล์ zip ที่แตกแล้วลงไป (ยกเว้นโฟลเดอร์ `node_modules` ถ้ามี) จากนั้นกด **Commit changes**

### 2. สร้างเว็บบน Render
1. สมัคร https://render.com ด้วยบัญชี GitHub
2. กด **New +** แล้วเลือก **Blueprint**
3. เลือก repo `phet-siam` ระบบจะอ่านไฟล์ `render.yaml` ให้เอง จากนั้นกด **Apply**
4. รอ 2–3 นาทีจนสถานะเป็น **Live** แล้วจะได้ลิงก์หน้าตาประมาณ `https://phet-siam.onrender.com`

### 3. เล่นกับเพื่อน
1. เปิดลิงก์ ใส่ชื่อ เลือกธีม (สยามโบราณ / แฟนตาซี / ไซไฟอวกาศ) แล้วกด **สร้างห้องใหม่**
2. กด **คัดลอก** แล้วส่งลิงก์ห้องให้เพื่อนใน Discord
3. พอเพื่อนเข้าครบแล้ว หัวห้องกด **เริ่มเกม** (ระหว่างรอ หัวห้องกด **ลบห้อง** ได้ ส่วนคนอื่นกด **ออกจากห้อง** ได้)

> แพ็กเกจฟรีของ Render จะหลับเมื่อไม่มีคนใช้ประมาณ 15 นาที การเปิดครั้งแรกหลังจากนั้นจะรอ 30–60 วินาที เป็นเรื่องปกติ
> ถ้าเซิร์ฟเวอร์รีสตาร์ทกลางเกม ทุกคนจะหลุดไปราว 1 นาที แล้วเกมจะกลับมาเองที่ตาเดิม เพราะทุกเครื่องเก็บสำเนาเกมที่เข้ารหัสไว้ (ใช้ค่า `SNAPSHOT_SECRET` ที่ Render สร้างให้อัตโนมัติจาก `render.yaml` ห้ามลบหรือเปลี่ยนค่านี้)

## วิธีเล่นสั้นๆ

ในตาของคุณ ทำได้ 1 อย่างจากนี้:
- **หยิบอัญมณี 3 สีไม่ซ้ำกัน**: กดอัญมณี 3 สี แล้วกด "หยิบ"
- **หยิบ 2 เม็ดสีเดียวกัน**: กดสีเดิม 2 ครั้ง (ทำได้เมื่อกองมีอย่างน้อย 4 เม็ด)
- **จองการ์ด**: กดการ์ดแล้วกด "จอง" หรือกดกองคว่ำเพื่อจองแบบไม่เห็นหน้าการ์ด จองแล้วได้ทอง 1 เม็ด ซึ่งใช้แทนสีอะไรก็ได้ (จองได้สูงสุด 3 ใบ)
- **ซื้อการ์ด**: กดการ์ดแล้วกด "ซื้อ" การ์ดที่มีกรอบสีเขียวคือใบที่ซื้อได้ทันที

การ์ดที่ซื้อแล้วให้ **โบนัสถาวร** ช่วยลดราคาการ์ดใบต่อไป เมื่อโบนัสครบตามเงื่อนไขของขุนนาง ขุนนางจะมาเยือนเอง ได้ 3 แต้ม
ใครถึง **15 แต้ม** ก่อน เกมจะเล่นต่อจนครบรอบนั้น แล้วคนที่มีแต้มมากที่สุดชนะ (ถ้าแต้มเท่ากัน คนที่มีการ์ดน้อยกว่าชนะ)

ถืออัญมณีได้ไม่เกิน 10 เม็ด ถ้าเกิน ระบบจะให้เลือกคืน

แต่ละตามีเวลา **1 นาที** ถ้าหมดเวลา ระบบจะข้ามตาให้เอง (ถ้าค้างอยู่ตอนคืนอัญมณีหรือเลือกขุนนาง ระบบจะทำให้อัตโนมัติ)

การ์ดที่เพื่อนจองจากกระดานจะแสดงในแผงของเพื่อน กดดูรายละเอียดได้ ส่วนใบที่จองคว่ำจากกองจะเห็นแค่หลังการ์ด

เกมมีเสียงประกอบแนวระนาด ปิด/เปิดได้ที่ปุ่ม **เสียง** มุมขวาบน

| ผู้เล่น | อัญมณีต่อสี | ขุนนาง | ทอง |
|---|---|---|---|
| 2 | 4 | 3 | 5 |
| 3 | 5 | 4 | 5 |
| 4 | 7 | 5 | 5 |
| 5 | 7 | 6 | 5 |

**ถ้ามีคนหลุด:** ให้เปิดลิงก์ห้องเดิมจากเบราว์เซอร์เดิม ระบบจะพากลับเข้าที่นั่งเดิมให้เอง ถ้าเปลี่ยนเครื่อง ให้ใส่รหัสห้องแล้วเลือก "เข้าแทน (ชื่อตัวเอง)" ระหว่างที่คนนั้นยังไม่กลับมา ถ้าถึงตาเขา หัวห้องกด "ข้ามตา" ได้

## สำหรับนักพัฒนา

```bash
npm test                          # unit + integration tests
node scripts/bot-playtest.js      # บอทเล่นจนจบเกม 2–5 คน
```

- `server/rules.js`: กติกาทั้งหมด (pure functions)
- `server/rooms.js` + `server/index.js`: ห้องและ Socket.io เซิร์ฟเวอร์เป็นผู้ตัดสินกติกาเพียงฝ่ายเดียว
- `public/`: หน้าเว็บ (ไม่ต้อง build)
- `public/assets/`: ภาพจาก PixelLab
